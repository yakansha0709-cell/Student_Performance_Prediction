🎓 About Student Performance Predictor

This project uses Machine Learning to predict student academic performance based on study hours, attendance and previous marks.

🚀 Project Objectives

To analyze academic factors and estimate student performance using a trained Machine Learning model.

🛠️ Technologies Used

Python, Flask, HTML, CSS, Machine Learning and CSV.

💡 Key Features

Performance Prediction, Analytics Dashboard, Prediction History and CSV Report Download.
