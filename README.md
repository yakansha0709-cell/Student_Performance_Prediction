 🎓 Student Performance Prediction System

## 📌 About the Project
Student Performance Prediction is an AI/ML-based web application designed to predict students' academic performance using various student-related factors.

The project helps understand student performance through data analysis, visualization, and machine learning predictions.

## ✨ Features
- Attractive and user-friendly website
- Student performance data analysis
- Data visualization with graphs
- Machine Learning prediction
- Student performance insights
- Interactive prediction interface

## 🛠️ Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- Pandas
- NumPy
- Scikit-learn
- Joblib

## 📂 Project Structure
- app.py – Flask application
- model.py – Machine Learning model
- - generate_data.py – Dataset generation
- templates/ – HTML templates
- static/ – CSS, JavaScript and other static files
- student_model.pkl – Trained ML model

## 🚀 How to Run the Project

1. Clone this repository.
2. Install the required libraries.
3. Run the application using:

bash
python app.py


4. Open the local URL displayed in the terminal.

## 🎯 Project Objective
To use Artificial Intelligence and Machine Learning to analyze student-related data and predict academic performance.
